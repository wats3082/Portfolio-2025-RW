Sentinel Ops

One contract-driven platform for access events, device health, video metadata, and operational KPIs—replacing disconnected security scaffolds with a coherent operator workflow.

Problem

Physical-security data lived across separate PACS, VMS, and KPI concepts with no shared contracts or deployment path.

Weather API v2

A React and AWS application that turns Open-Meteo forecasts into city, route, and demonstration turbulence-risk views with explicit boundaries around the model.

Problem

Weather lookup and route context require several data and caching decisions before they become useful in one workflow.

Approach

Combined a Vite frontend with TypeScript Lambda handlers, API Gateway, CDK, Cognito-protected saved locations, and DynamoDB TTL caching.

Evidence

Supports current conditions, five-day forecasts, route search, input validation, unit-tested cache behavior, and a five-factor heuristic.
